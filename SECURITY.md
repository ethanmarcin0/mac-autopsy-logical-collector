# Security policy

## Supported version

Security fixes are made against the current version on the default branch.

## Reporting a vulnerability

Please do not post potential security vulnerabilities, sensitive sample data, device identifiers, passwords, or evidence files in a public issue.

Instead, contact the repository owner privately with:

- a short description of the issue;
- steps to reproduce it using harmless test data;
- the affected application version and macOS version; and
- any suggested mitigation.

The project is an educational tool. Reports involving bypassing device security, accessing data without authority, or collecting protected data are out of scope and will not be implemented.
